# Advanced Illusion Engine V2

A single-file WebGL optical illusion engine that generates animated GPU-powered op-art patterns, warped grids, bulging spheres, vortex tunnels, moiré fields, chromatic distortions, and neural-style lattice drift.

The project runs entirely in the browser with no external libraries, no build step, and no installation.

---

## Demo

Open the HTML file in a modern browser and interact with the illusion in real time.

Move your mouse or finger to steer the distortion lens.

---

## Features

- GPU-powered WebGL fragment shader rendering
- 6 illusion modes:
  - Hyper Bulge Sphere
  - Vortex Tunnel
  - Impossible Checker Dome
  - Liquid Moiré Field
  - Neural Lattice Drift
  - Kaleido Lens
- Real-time distortion controlled by pointer movement
- Touch support for mobile and tablets
- Scroll wheel intensity control
- Adjustable grid density
- Adjustable zoom
- Adjustable animation speed
- Chromatic aberration control
- Noise/grain control
- Multiple color palettes:
  - Mono Cyan
  - Infrared Magenta
  - Black / White
  - Prismatic
  - Amber Night
- Adaptive render quality settings
- PNG export
- Fullscreen mode
- Pause/play control
- Randomizer
- FPS counter
- Shader compile error handling
- WebGL fallback message
- Single-file portable HTML app

---

## Controls

### Mouse / Touch

| Action | Effect |
|---|---|
| Move pointer | Steer the illusion lens |
| Scroll wheel | Increase/decrease distortion intensity |
| Click/tap canvas | Cycle illusion mode |

### Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Pause / play animation |
| `H` | Hide / show UI |
| `R` | Randomize settings |
| `S` | Save PNG screenshot |
| `F` | Toggle fullscreen |
| `M` | Cycle illusion mode |
